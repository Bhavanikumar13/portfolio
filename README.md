# Yelleti Bhavani Kumar - Professional Portfolio

A modern, responsive, and beautifully designed personal portfolio website built with React and Vite. This application showcases my professional objective, education, technical skills, and past projects.

## 🚀 Features

- **Modern Glassmorphism UI**: Beautiful and interactive UI elements with glass-card effects and ambient lighting.
- **Scroll Animations**: Smooth intersection-observer based animations that trigger as you scroll.
- **Responsive Layout**: Designed to look great on desktop, tablet, and mobile devices.
- **Organized Sections**:
  - **Hero**: Quick introduction, contact details, social links, and resume download.
  - **About Me**: Professional objective, personal details, and interests.
  - **Education**: Timeline of educational background and achievements.
  - **Technical Skills**: Categorized skills (Languages, Web Dev, Core & Data, Tools, Soft Skills).
  - **Projects**: Grid layout showcasing recent development projects.

## 🛠️ Technologies Used

- **React 19**: Modern UI library for building component-based interfaces.
- **Vite**: Next-generation frontend tooling for fast build times and hot module replacement.
- **CSS3**: Custom styling, animations, and responsive design variables.
- **React Icons**: Utilizing feather icons (`react-icons/fi`) for clean vector graphics.

## 🏃‍♂️ Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- [Node.js](https://nodejs.org/) installed on your local machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Bhavanikumar13/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server, run:

```bash
npm run dev
```

By default, the Vite server will start on `http://localhost:5173/`.
You can also use `npm run host` to expose the local server on your network.

## 📁 Project Structure

- `src/App.jsx` - The main React component containing the entire portfolio structure and layout.
- `src/App.css` - Styles for the application, including custom CSS variables, glassmorphism utilities, and animations.
- `src/index.css` - Base styling resets and font configurations.
- `package.json` - Project metadata, scripts, and dependency definitions.
